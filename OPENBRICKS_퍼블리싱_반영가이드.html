경로 변환

퍼블리싱은 로컬에서 열 수 있게 상대경로를 씁니다. 실서비스로 옮길 때 아래 규칙을 적용하세요.

필수: CSS 폰트 경로. 퍼블리싱 style.css는 폰트를 ../../common/webfont/로 부릅니다. 실서비스 폰트는 /webfont/에 있으므로, 그대로 올리면 /common/webfont/…를 찾다가 폰트가 깨집니다. 교체 전에 120곳을 한 번에 치환하세요.

JS 연동 주의 (Blazor)

실서비스는 /js/common.bundle.js 하나로 swiper와 common을 함께 불러옵니다. 새 common.js로 번들을 다시 만들어 주세요. 퍼블리싱 JS는 정적 페이지 기준이라 DOMContentLoaded에서 한 번 초기화하는데, 실서비스처럼 렌더할 때마다 초기화 함수를 다시 부르면 클릭 리스너가 쌓입니다. QA에서 나온 "메뉴가 안 닫힘", "짝수 번째 이동 후 메뉴가 안 열림"의 원인입니다.

레이아웃에서 최초 1회만

allMenu() · mobileMenu() · quickTop()

헤더·퀵버튼처럼 페이지가 바뀌어도 남는 요소입니다. MainLayout의 OnAfterRenderAsync(firstRender)에서 firstRender일 때만 호출하세요.

각 페이지의 첫 렌더에서

introView()(홈) · serviceSlider() · comTabMobile() · refAccordion() · logoRolling() · contactInput() · contactForm() · fixedTap()

요소가 없는 페이지에서는 그냥 빠져나가므로 에러는 나지 않습니다.

  • 페이지 이동 시 메뉴 닫기: 퍼블리싱 JS는 메뉴 링크 클릭 때 닫지만, NavigationManager.LocationChanged에서도 닫아 주세요. 닫힌 상태는 .cptGnb, .quickArea, .allMenuBox에 active가 없고 body에 noScrl이 없는 상태입니다.
  • GNB_BREAKPOINT = '(max-width: 1280px)'는 SCSS pc 브레이크포인트와 같은 값입니다. 한쪽만 바꾸지 마세요.
  • 메인 슬라이드: slidesPerView: "auto", loop: false, 자동재생 4초. 카드 폭은 CSS(380px / 모바일 276px)가 정합니다.
  • QA에서 지적된 F5/Ctrl+R 차단 스크립트와 서브페이지 주소로 직접 접속하거나 새로고침하면 서버가 404를 주는 문제(SPA 폴백 설정 필요)는 실서비스 쪽 이슈라 퍼블리싱 파일과 무관합니다.
